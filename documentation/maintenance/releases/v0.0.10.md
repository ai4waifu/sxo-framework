# 🚀 v0.0.10

## ✨ Features

- **Complex vertical**: imaginary-unit scalar multiply, `Arg` on principal-axis reals, machine-complex part ops, and conjugate-pair multiply on both Mathematica and MATLAB.
- **Matrix exponential**: `MatrixExp` / `expm` on skew-symmetric `2×2`, zero-diagonal, and diagonal integer generators.
- **Spectral and stats**: Mathematica `Eigenvalues`, `Eigenvectors`, and `Mean`; symmetric `2×2` eigenvector layout flags on both dialects.
- **Polynomial algebra**: `Expand`, `Factor`, `Collect`, `PolynomialGCD`, `Together`, `Apart`, `Cancel`, `Coefficient`, `Exponent`, `Variables`, `Discriminant`, `Resultant`, and `PolynomialRemainder`.
- **Elementary specials**: `Gamma`, `Erf`, `UnitStep`, inverse-trig boundary values, `Tanh` at zero, `ArcCos`/`ArcTan`, `Numerator`/`Denominator`, `Sinc`, and exact integer `Normalize`.
- **Mathematica predicates and domains**: `StringQ`, `Positive`, `VectorQ`, `MatrixQ`, `BooleanQ`; `Element[_, Integers|Reals|Complexes]`; imaginary unit `I` lowering.
- **Mathematica comparisons and rounding**: `UnsameQ`, `Inequality`, `=!=` desugar, n-ary `GreaterEqual`, `Max`/`Min`, `Sign`, `Nearest`, `Floor`/`Ceiling`, `Clip`/`Rescale`, `CubeRoot`/`Surd`.
- **MATLAB vectors**: `linspace` and `logspace` materialize as `1×n` machine row vectors.
- **KroneckerProduct**: matrix-block `KroneckerProduct` and MATLAB `kron` on tested shapes.
