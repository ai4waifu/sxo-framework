# 🚀 v0.0.4

## ✨ Features

- **`@sxo/core` module split**: CAS surface exported as isomorphic modules; `@sxo/lite` mirrors the same layout.
- **Mathematica control surface**: `While` / `Do`, `ReleaseHold` / `Evaluate`, boolean and logic lowering; new `MatlabForm` dialect `Form` type.
- **`@sxo/sxo` CLI**: explicit-dialect `features` routing; harness discovers matrices via package `sxo.featureMatrix`.

## 🐛 Bug Fixes

- Mathematica and MATLAB `Power` rendering now parenthesizes compound bases and negative or rational exponents.
