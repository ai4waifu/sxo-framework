# 🚀 v0.0.9

## ✨ Features

- **Living 16 matrix vertical**: MATLAB `reshape` / `numel` / `size` / column-vector `sum` / `prod` / `max` / `min` / `transpose` scalar folds; Mathematica `ArrayReshape` (row-major) separate from MATLAB column-major `reshape`; rank-1 `TensorProduct` as outer-product `MatMul`; shared dense matrix literal lowering for both dialects.
- **NestedRows structure projection**: flat Mathematica vectors stay `{1,2,3}` for `Range`, `ConstantArray`, `Accumulate`, `Differences`, and structure ops (`First` / `Rest` / `Flatten` / `Extract` / `Append` / `Join` / `PadLeft` / `Take` / `Drop`); nested matrices keep row blocks.
- **Mathematica list operators**: `EvenQ`, `Select`, `ListConvolve`, and `MapAll` with predicate/func capture on elaboration.
- **Mathematica predicates**: `IntegerQ`, `AtomQ`, `ListQ`, `NumericQ`, `NumberQ`, and `PossibleZeroQ`.
- **List membership and comparisons**: `MemberQ`, `Count`, `Length`, list `Less` broadcast, and elementwise `Equal` / `Unequal` on both dialects.
- **ArrayFlatten**: one-level flatten on nested row blocks with singleton-row unwrap.
- **Empty matrices**: zero-element MATLAB constructors render `[]`; `Dimensions` / `size` / `numel` contracts locked on empty shapes.

## 🐛 Bug Fixes

- Zero-element MATLAB matrices render as `[]` instead of malformed literals.
- Surface `If` assignments and MATLAB scalar `i` / `j` in nested `While` loops evaluate correctly.

## 🧪 Parity

- Extended `@sxo/lite` WASM list and matrix parity smoke for Living 16 matrix and list contracts.
