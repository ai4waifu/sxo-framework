# 🚀 v0.0.6

## ✨ Features

- **Matrix operations**: MATLAB and Mathematica `*` / `.*` / `/`, `det` / `inv` / `rank` / `norm` / `cross`, and related goals through `MatrixOperand` lowering.
- **List and symbol surface**: Mathematica `Append`, `Flatten`, `MapThread`, `Sort`, and peers; `HoldComplete` / `Unevaluated` and MATLAB `Cell` / `Command` forms.
- **Host API**: `simplify()` and `d()` aligned on N-API and WASM to a single `ResultId` chain; `Expression` exposes a `provider` stamp.
