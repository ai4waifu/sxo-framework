# 🚀 v0.0.5

## ✨ Features

- **Matrix linear algebra lowering**: `Dot`, `Inverse`, `LinearSolve`, `Transpose`, and related goals via `MatrixValue` and `LinearAlgebraRequest`.
- **Evaluation semantics**: N-API and WASM `Expression` share `Session` evaluation; `EvalOutcome` and Athena status axes exposed; unified `autoSimplify` strategy.
- **Scopes and MATLAB control**: `Module` / `Block` / `With`; anonymous functions, `switch`, and `feval` mapping; `@sxo/pari-gp` placeholder package and Feature Matrix routing.
