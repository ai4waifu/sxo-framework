# 🚀 v0.0.7

## ✨ Features

- **Comparison and integer arithmetic**: Mathematica `SameQ` / `Identical` and `Mod` / `Quotient` / `IntegerDigits` evaluation paths.
- **Exact complex matrix surface**: conjugate transpose, Hadamard, Kronecker, and axis-aware `sum` / `prod` / `Total` lowering; MATLAB dynamic `Part` indexing and two-sum-style control flow.
- **Honest Feature Matrix marks**: many dialect subsets move from overstated `supported` to `partial`, with N-API and WASM Session parity on the same host contract.
- **Harness**: `HostSession` load / bind / invoke contract; Feature Matrix `suboptimal` and `cosmetic` triage flags.

## 🐛 Bug Fixes

- Mathematica `Do` / `Return` anchors for dynamic iterators and arithmetic `Part`.
- Unevaluated `Application` diagnostics when `termToJson` fails.
