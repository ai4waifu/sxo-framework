# Native Platform Artifact: macOS x64

This package contains the macOS x64 native SXO addon selected by the supported high-level packages. Application developers should install `@sxo/core`, `@sxo/sxo`, or a dialect package rather than importing this implementation artifact.

The binary must match the operating system, CPU architecture, Node.js ABI, and package version. Test clean deployment hosts and preserve diagnostics when loading fails. Apache License 2.0. See [LICENSE](../../../../LICENSE).
