# Native Platform Artifact: Windows x64

This package contains the Windows x64 native SXO addon selected automatically by a supported high-level package. End users should install `@sxo/core`, `@sxo/sxo`, or the dialect package they need. Do not import this platform artifact directly unless you are debugging package-manager resolution.

The binary targets Windows x64 and the Node.js ABI supported by the release. Installation can fail when the operating system, CPU, Node.js version, or generated artifact does not match.
